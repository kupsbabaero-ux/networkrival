# Philippine TV EPG (XMLTV)

Electronic Program Guide for major Philippine free-to-air and cable channels in standard **XMLTV** format.

## Channels Included
| ID | Channel |
|----|---------|
| TV5.ph | TV5 (5 Network) |
| Kapamilya.ph | Kapamilya Channel |
| ALLTV2.ph | ALLTV2 (ABS-CBN on free TV) |
| A2Z.ph | A2Z |
| JeepneyTV.ph | Jeepney TV |
| GMA.ph | GMA Network |
| GTV.ph | GTV |

## Files
- `epg/ph-tv-epg.xml` — Main EPG (XMLTV)
- `epg/ph-tv-epg.xml.gz` — Compressed version (generated by workflow)
- `.github/workflows/update-epg.yml` — Auto-updates dates/times daily

## Usage
Point your IPTV player / PVR / TiviMate / Jellyfin / etc. to the raw XML:

```
https://raw.githubusercontent.com/YOUR_USERNAME/ph-tv-epg/main/epg/ph-tv-epg.xml
```

Or the gzipped version for smaller downloads.

## Auto Update
GitHub Actions runs daily (or on push) and:
1. Regenerates programme `start`/`stop` times relative to the current date
2. Updates the `<tv date="...">` attribute
3. Commits the refreshed EPG

## Local Generation
```bash
python scripts/generate_epg.py
```

## Notes
- Schedules are approximate and based on publicly available line-ups (Oct 2026).
- Dramas and specials change frequently — treat this as a template/base.
- Timezone: Asia/Manila (UTC+8)
- Format: XMLTV 0.5+ compatible
